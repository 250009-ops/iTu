# Teacher Portal — Phase 2 (Deferred UI)

Features intentionally omitted from v1 teacher UI because they are not yet implemented end-to-end. Do not surface placeholder buttons or dead links in the live product.

## Speaking Sessions

| Feature | Description | Target |
|---------|-------------|--------|
| **Session Details drawer** | Side panel with enrollment context, mock package, student contact (masked), integrity flags, and speaking recording metadata | Phase 2 |
| **Live device self-check** | Real mic/camera/network validation on the hub hero before entering console (currently shown as informational badges only) | Phase 2 |
| **Awaiting grade in Completed tab** | Sessions ended but not yet scored could appear in a separate sub-tab | Phase 2 |

## Writing Grading

| Feature | Description | Target |
